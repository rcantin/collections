# Collections

Public checklist app for personal collections.

Live site: https://rcantin.github.io/collections/

Collections in the dropdown:
- Comic Books (from [this sheet](https://docs.google.com/spreadsheets/d/1ayhk7-di_woCB-Yn7xJXLF89zmaUSlXX-fpAsONAztY))
- Trading Cards (from [this sheet](https://docs.google.com/spreadsheets/d/1AX6MCDmu-zMOzwaj09jc4XKSit8SzFycUWxLtjgcfS0))
- Action Figures, Beanie Babies, Coins, Stamps (placeholders)

The app tries the live Google Sheet first, then falls back to the JSON snapshots in `data/`. Checkmarks are stored in the browser.
